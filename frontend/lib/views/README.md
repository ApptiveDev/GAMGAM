# View routes

- `home/`: upcoming and past appointments
- `appointment_create/`: template selection and name input
- `room/`: time/place voting and invite state
- `penalty/`: late penalty agreement
- `confirmed/`: confirmed appointment and install prompt
- `location/`: per-room location sharing settings
- `live_map/`: day-of map and participant ETA
- `poke/`: poke bottom sheet and notification UI
- `arrival/`: arrival order and penalty result
- `records/`: past-meeting statistics and replay entry

The current starter implements the home, appointment-create, and records views. Add the remaining views in their matching folders as each flow is developed.
