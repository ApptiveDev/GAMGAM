# GAMGAM Flutter Frontend

GAMGAM의 모바일/웹 프론트엔드입니다.

## 시작하기

1. [Flutter SDK](https://docs.flutter.dev/get-started/install)를 설치합니다.
2. 이 폴더에서 플랫폼 프로젝트를 생성합니다.

   ```bash
   flutter create .
   ```

3. 의존성을 받고 앱을 실행합니다.

   ```bash
   flutter pub get
   flutter run
   ```

`lib/main.dart`에 앱의 시작 화면이 있습니다. 플랫폼별 설정은 `android/`, `ios/`, `web/` 등이 생성된 뒤 관리합니다.
